# rule-sets

Публичный репозиторий: списки доменов и IP-сетей для mihomo, собранные в `.mrs`. Потребители забирают их через
jsdelivr.

**Репозиторий публичный.** Сюда не попадает ничего, кроме самих списков и их сборки: ни сведений об
инфраструктуре, ни ссылок на приватные репозитории, ни личных данных. Коммиты идут с noreply-адреса,
он задан в настройках этого репозитория (`git config user.email`) — не менять.

## Структура

| Путь | Что |
|---|---|
| `src/domain/*.yaml` | списки доменов — правятся руками |
| `src/ipcidr/*.yaml` | списки IP-сетей — правятся руками |
| `tools/` | скрипты, которые вызывает CI |
| `mrs/*.mrs` | собранные списки — пишет только CI |
| `docs/lists.md` | что в каких списках, формат записей |
| `docs/ci.md` | как устроена сборка и почему |

## Инварианты

1. **Адреса `mrs/<имя>.mrs` — публичный контракт.** На них ссылаются потребители; переименование или
   перенос ломает их. Любая смена адреса — только с переходным периодом, пока старые копии лежат на месте.
2. **В исходниках и workflow нет комментариев** — пояснения в `docs/`.
3. **`.mrs` руками не правится** — только через `src/` и CI.
4. **Версия mihomo закреплена** вместе с SHA256: версия формата зашита в заголовок `.mrs`, старые ядра
   не читают другие версии. Обновление — навык `bump-mihomo`.
5. **Тип списка — папка** (`domain`/`ipcidr`). Перенос файла между папками меняет тип `.mrs` и ломает
   потребителей с прежним `behavior`. Имена по всем папкам уникальны. `classical` в `.mrs` не бывает.

## Как работать

- Правка списков — навык `update-lists`: поправить `src/`, запушить, дождаться CI, при необходимости
  сбросить кеш jsdelivr.
- Утверждения о поведении mihomo подтверждать исходниками со ссылкой на файл, а не wiki.
- Общение по-русски и коротко.

## Инструменты (Windows)

- Bash — это Git Bash. Для вывода Python с эмодзи и кириллицей — `PYTHONIOENCODING=utf-8`.
- Python, переданный через heredoc, терял обратные слэши: `\b` превращался в `0x08`. Скрипты писать
  в файлы или собирать `\` через `chr(92)`.
- Исходники mihomo удобнее брать через `cdn.jsdelivr.net/gh/MetaCubeX/mihomo@Alpha/...`.
- Статус сборки: `gh run list -R nargothrondir/rule-sets`.
