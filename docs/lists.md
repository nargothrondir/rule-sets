# Списки

Тип списка задаёт папка исходника: `src/domain/` — домены, `src/ipcidr/` — IP-сети. Потребитель
указывает тот же `behavior`, иначе ядро откажется читать файл (`invalid behavior`).

| Исходник | Собранный | Тип | Назначение |
|---|---|---|---|
| `src/domain/proxy.yaml` | `mrs/proxy.mrs` | domain | домены, которые должны идти через прокси |
| `src/domain/direct.yaml` | `mrs/direct.mrs` | domain | домены, которые должны идти напрямую |
| `src/ipcidr/discord-voice.yaml` | `mrs/discord-voice.mrs` | ipcidr | сети голосовых серверов Discord |

## `proxy`

- **Сервисы определения IP** — `ipwhois.app`, `ipwho.is`, `api.ip.sb`, `ipapi.co`, `ipinfo.io`. Чтобы
  проверки IP в клиентах показывали адрес выхода прокси, а не реальный.
- **Прочие ресурсы** — всё остальное в списке.

## `direct`

Поиск Google: `google.com`, `google.ru` и их `www`, `search.google.com`.

## `discord-voice`

Сети, где работают голосовые серверы Discord: Google Cloud, собственные сети Discord, Cloudflare.
Сети широкие (в них живёт много чужих сервисов), поэтому список рассчитан на использование вместе
с условием по протоколу и портам, например
`AND,((NETWORK,udp),(DST-PORT,19294-19344/50000-50100),(RULE-SET,discord-voice,no-resolve)),<группа>`.

## Формат записей

### Домены

```yaml
payload:
  - 'example.com'      # только сам домен
  - '+.example.com'    # домен и все поддомены
  - '.example.com'     # только поддомены
  - '*.example.com'    # ровно один уровень поддоменов
```

Правила разбора — `component/trie/domain.go` в mihomo: `+` допустим только целой первой меткой,
`*` — только целой меткой.

### IP-сети

```yaml
payload:
  - '192.0.2.0/24'
  - '198.51.100.7/32'   # отдельный адрес — только с маской
  - '2001:db8::/32'
```

- адрес без маски mihomo молча выбрасывает (`invalid Ipcidr`, код выхода 0) — сборка считает это ошибкой;
- при сборке соседние сети склеиваются, биты хоста обнуляются: `34.0.0.0/15` и `34.2.0.0/15` в файле
  станут `34.0.0.0/14`. Поэтому содержимое сверяется по множеству адресов, а не построчно
  (`tools/compare_ipcidr.py`).

### Общее

- регистр не важен: mihomo приводит записи к нижнему;
- пробелы внутри записи и ссылки вместо доменов — ошибка сборки: mihomo такие молча выбрасывает
  или хранит как мусор;
- пустой список — ошибка сборки;
- повтор записи — предупреждение. Содержимое `.mrs` от повтора не меняется, но байты файла — да;
- правила с условиями (`classical`: `DOMAIN-KEYWORD`, `AND`, порты) в `.mrs` не собираются — формат
  поддерживает только `domain` и `ipcidr`.
